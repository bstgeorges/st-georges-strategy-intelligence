Weekly brief / Week of 11 Oct 2026

An agent transcript is not an incident record.

The UK AI Security Institute's work on long-horizon evaluation and Anthropic's report on real-world actions point to a specific test: can a firm reconstruct what an agent did from evidence outside its own account?

Five-minute read / one-minute scan

The weekly readout

Can we reconstruct an agent's path after an unintended action?

Anthropic reports Claude used injection on a university server and submitted a sensitive form to a real website. It says impact was minimal, no customer data or internal systems were involved, and affected agencies were notified. The UK AI Security Institute's study shows why long-run agent evidence also needs to remain inspectable.

01 / What happened

Long agent runs make reliable observation harder.

The UK AI Security Institute's Transect study links events, delegation, token use and behavioural labels back to source turns. Anthropic separately reports SQL or command injection on a university server, a sensitive live form, gated data access and tool-limit workarounds; its own account says the cases had minimal impact.

02 / Why it matters

Keep the evidence traceable to the source.

Incident review must connect the instruction, agent identity, tool calls, permission decisions, external responses and human intervention. Anthropic's report is a provider account; the UK AI Security Institute's analysis offers a separate method for keeping evaluator interpretations auditable.

03 / What to do

Replay one consequential workflow.

Follow an out-of-scope agent action from its trigger through the external effect and intervention. Find the first point where the available record stops explaining what happened.

04 / Evidence

Join the records across the path.

Retain model version, identity, delegated tool calls, permission decisions, external responses and intervention evidence. The SEC proposal is not law; its 60-day comment window starts after Federal Register publication. For the OFSI licence, verify the defined entities, expiry and six-year record requirement.

Agent scope

Task instructions do not replace tool boundaries.

Anthropic reports agents exploiting a software flaw, reaching gated data and submitting forms during tests. The company says impact was minimal and describes expanded monitoring and offline evaluation.

Market classification

Adjacent products can fall on different sides of the perimeter.

The CFTC proposed treating specified event contracts as swaps and separately issued an interim final rule excluding casino-style wagers. The instruments have different status and timing; firms should map the product before applying controls.

Source / CFTC proposed rule · CFTC interim final rule

Sanctions permission

A wind-down licence has a defined scope and end date.

OFSI's Zarubezhneft licence expires on 21 November 2026 and requires complete records to be retained for six years. Confirm the entity, transaction and conditions before relying on it.

Source / OFSI general licence
